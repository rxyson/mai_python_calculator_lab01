# Консольный калькулятор и конвертер величин

## Описание проекта

Проект представляет собой консольное приложение на Python, которое позволяет вычислять математические выражения и преобразовывать значения между единицами измерения.

Приложение использует командный интерфейс CLI. Для обработки аргументов командной строки применяется модуль argparse.


## Возможности

### Калькулятор

Калькулятор может работать с целыми и дробными числами

Поддерживаются такие операции, как:

- сложение `+`
- вычитание `-`
- умножение `*`
- деление `/`

Также есть возможность использовать как положительные, так и отрицательные числа, используя унарные знаки `+` и `-`.

Калькулятор умеет правильно учитывать порядок действий и игнорирует лишние пробелы. Например:

- `5 + 10 * 8`
- `5       + 10        *        8`

Оба выражения обработуются без проблем и дадут результат: 85.0

### Конвертер

Конвертер поддерживает 3 группы единиц:

- Длина

Поддерживаются:
mm - миллиметры
cm - сантиметры
m - метры
km - километры

- Масса

Поддерживаются:
g - граммы
kg - килограммы

- Температура

Поддерживаются:
с - градусы Цельсия
f - градусы Фаренгейта
k - Кельвины

## Свойства программы

Проверка входных данных и обработка ошибок.

Вывод справки с помощью аргумента --help .

Автоматические тесты для проверки работы приложения

Отсутствие учитывания регистра единиц в конвентере. Cm, CM, cm буду вопсприниматься одинаково.

Температуры ниже абсолютного нуля программа не принимает.

Отсутствие возможности перевода единиц из разных групп. Если попробовать перевести из сантиметров в граммы, то программа выдаст ошибку.

## Требования

- Python версии 3.12 или выше.
- pip для установки проекта и его зависимостей.

## Процесс установки

1) Клонируйте репозиторий
```shell
git clone https://github.com/rxyson/mai_python_calculator_lab01.git
cd mai_python_calculator_lab01
```

2) Создайте виртуальное окружение

MacOs / Linux
```shell
python3 -m venv .venv
source .venv/bin/activate
```

Windows (Powershell)
```shell
py -m venv .venv
.venv\Scripts\Activate.ps1
```

Windows (Command Promt / cmd)
```shell
py -m venv .venv
.venv\Scripts\activate.bat
```

После активации установите проект и его зависимости.
```shell
python -m pip install -e .
```

## Использование

Запуск калькулятора
```shell
python -m toolkit calc "5 + 10 * 8"
```

Запуск конвертера
```shell
python -m toolkit convert 5 --from km --to m
```

Просмотр справки
```shell
python -m toolkit --help
```

Просмотр справки по калькулятору
```shell
python -m toolkit calc --help
```

Просмотр справки по конвертеру
```shell
python -m toolkit convert --help
```

При успешном выполнении программа возвращает код завершения 0. При ошибке вычисления или преобразования возвращается код 2, а сообщение об ошибке выводится в стандартный поток ошибок.

## Назначение модулей

- calculator.py - токенизация, проверка и вычисление математических выражений.
- converter.py - преобразование единиц длины, массы и температуры.
- errors.py - пользовательское исключение ToolkitError.
- __main__.py - командный интерфейс приложения.
- tests/ - автоматические тесты калькулятора, конвертера и CLI.
- pyproject.toml - метаданные проекта и настройки инструментов разработки.
- .pre-commit-config.yaml - настройки автоматических проверок кода.
